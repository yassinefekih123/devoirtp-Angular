# Devoir TP Angular – Accueil, inscription et connexion

Petite application Angular 20 (avec rendu côté serveur) réalisée dans le cadre d'un TP : navigation entre trois pages et gestion simple de l'authentification.

## Fonctionnalités

- Page d'accueil
- Formulaire d'inscription
- Formulaire de connexion
- Service d'authentification (`AuthService`) qui conserve l'état de connexion dans le navigateur
- Routage Angular entre les pages

## Technologies

- Angular 20 avec `@angular/ssr`
- TypeScript, HTML, SCSS

## Lancer le projet

```bash
git clone https://github.com/yassinefekih123/devoirtp-Angular.git
cd devoirtp-Angular
npm install
ng serve
```

Ouvrir http://localhost:4200/.
